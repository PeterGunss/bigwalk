# 한글(HWP) ↔ Zotero 연동 프로젝트

## 목표

Zotero의 Microsoft Word 애드인과 비슷하게, 아래한글(한컴오피스 2024 이상, **Windows 전용**)에서
Zotero 인용을 삽입/관리할 수 있게 만드는 것이 최종 목표입니다.

이 문서는 실행 환경(Windows + 한컴오피스 한글)에서만 의미가 있습니다. 이 리포지토리 작업은
Linux 환경에서 이루어지므로, 아래 스크립트들은 **사용자가 직접 Windows PC에서 실행하고
결과를 알려주는 방식**으로 검증합니다.

## 왜 두 단계(Tier)로 나누는가

Zotero가 Word/LibreOffice에서 쓰는 실제 통합 방식(HTTP Integration Protocol)은
`Document.getFields`, `Field.setCode`, `Document.insertField` 등 15~20개의 명령을 문서
필드(누름틀) 모델에 정확히 매핑해서 구현해야 하는, 꽤 규모가 큰 프로젝트입니다.
처음부터 이걸 목표로 하면 검증에 오래 걸리고 실패했을 때 원인을 찾기도 어렵습니다.

그래서 다음과 같이 나눕니다.

- **Tier 1 (지금 진행 중) — "클립보드 삽입기"**
  Zotero에서 인용을 복사(Quick Copy)한 뒤, 한글 문서의 커서 위치에 서식과 함께
  바로 꽂아주는 도구. 완전한 실시간 연동은 아니지만 당장 실사용 가치가 있고,
  한글 자동화 자체가 이 컴퓨터에서 정상 동작하는지를 확인하는 발판이 됩니다.
- **Tier 2 (Tier 1 성공 후 검토) — "진짜 연동"**
  Zotero의 HTTP Integration Protocol을 구현해서 인용을 누름틀로 문서에 저장하고,
  스타일을 바꾸면 문서 전체가 갱신되는 수준까지 가는 것. Tier 1이 잘 동작하는 걸
  확인한 다음, 명령어 하나씩 나눠서 진행합니다.

## 사용 라이브러리

- [`pyhwpx`](https://pypi.org/project/pyhwpx/): 한글 오토메이션(COM) API를 파이썬에서 쉽게
  쓸 수 있게 감싼 오픈소스 패키지. 보안모듈 등록도 자동으로 처리해줍니다.

## 사전 준비 (Windows PC에서)

1. Windows에 한컴오피스 한글(2024 이상)이 정식 설치되어 있어야 합니다.
2. Python 3.9 이상 (이미 설치되어 있다고 하셨습니다).
3. VS Code 터미널에서 이 리포지토리를 클론(또는 내려받기)한 뒤, 아래 명령 실행:

   ```
   cd hwp_zotero
   pip install -r requirements.txt
   ```

## Stage 0 — 환경 점검

한글 자동화가 이 컴퓨터에서 정상적으로 동작하는지 확인하는 스크립트입니다.
**한글을 미리 켜두지 않아도 됩니다** — 스크립트가 자동으로 한글을 실행합니다.

```
python 00_check_env.py
```

- 한글 창이 뜨고, 새 문서에 테스트 문장이 자동으로 입력되면 성공입니다.
- 터미널에 `[성공]`으로 시작하는 메시지가 나오면 저에게 그 내용을 그대로 알려주세요.
- 에러가 나면 에러 메시지 전체를 그대로 복사해서 알려주세요. (개인정보가 포함된 경로 등은
  가려도 됩니다.)

Stage 0가 성공적으로 확인되었습니다 (한글 자동화 연결 정상 동작).

## Stage 1 — 클립보드 삽입기

Zotero에서 복사한 인용을, 지금 한글에서 커서가 있는 위치에 그대로 넣어주는 스크립트입니다.

1. requirements.txt가 바뀌었으니 다시 설치해주세요.

   ```
   pip install -r requirements.txt
   ```

2. 한글에서 원하는 문서를 열고, 인용을 넣을 위치에 커서를 둡니다. (이번에는 한글을
   미리 켜두셔야 합니다 — 이미 열려 있는 문서에 연결하는 방식입니다.)
3. Zotero에서 인용할 항목을 선택하고 "인용 복사"(예: `Ctrl+Shift+C`)를 실행합니다.
   - 어떤 서식(스타일)으로 복사될지는 Zotero 환경설정 > 내보내기(Export) 탭의
     "빠른 복사(Quick Copy)" 설정에서 미리 정할 수 있습니다.
4. 터미널에서 실행:

   ```
   python 01_insert_clipboard.py
   ```

5. 한글 문서의 커서 위치에 클립보드 내용이 그대로 삽입되면 성공입니다.

Stage 1도 성공적으로 확인되었습니다.

## 최종 목표 재정리 (Word 애드인 수준 + .exe 배포)

다음 목표는 "Word 애드인처럼 느껴지는 사용성"과 "Python 없이 실행되는 배포판" 두 가지입니다.
이를 위해 순서를 다음과 같이 잡았습니다.

- **Stage 2 (지금)** — 터미널에서 매번 스크립트를 실행하지 않고, 단축키 한 번으로 삽입.
- **Stage 3 (다음)** — PyInstaller로 `.exe` 파일로 패키징해서 Python 설치 없이 실행.
- **Stage 4+ (그다음, 가장 오래 걸림)** — Zotero의 HTTP 통합 프로토콜을 구현해서 인용을
  누름틀(필드)로 저장하고, 스타일 변경 시 문서 전체가 갱신되는 수준까지 (Tier 2).

## Stage 2 — 단축키 리스너

터미널을 열어둔 채로 실행해두면, 이후에는 단축키 한 번으로 클립보드 내용을 한글에 넣을 수 있습니다.

1. requirements.txt가 또 바뀌었으니 다시 설치해주세요.

   ```
   pip install -r requirements.txt
   ```

2. 실행:

   ```
   python 02_hotkey_listener.py
   ```

   "리스너를 시작합니다..." 메시지가 뜨면 이 창은 그대로 열어두세요 (최소화 가능).

3. 한글 문서에서 커서를 원하는 위치에 두고, Zotero에서 "인용 복사"를 실행합니다.
4. **`Ctrl+Alt+Z`**를 누르면 클립보드 내용이 한글에 삽입됩니다. 성공하면 짧은 "삐" 소리가
   나고, 실패하면 낮은 "부-" 소리가 납니다.
5. 리스너를 끝내려면 그 터미널 창에서 `Ctrl+C`.

만약 단축키를 눌러도 반응이 없다면, VS Code 터미널(또는 명령 프롬프트)을
**"관리자 권한으로 실행"** 한 뒤 다시 시도해주세요. (전역 단축키 후킹에 권한이
필요한 경우가 있습니다.)

Stage 2도 성공적으로 확인되었습니다. (성공 알림 소리는 나중에 손볼 예정이며, 기능에는
영향이 없습니다.)

## Stage 3 — .exe 패키징 (Python 없이 실행)

PyInstaller로 `02_hotkey_listener.py`를 `.exe` 파일 하나로 묶습니다. 이 단계는
지금 사용 중인 컴퓨터에서 "빌드"만 하고, 나온 `.exe` 파일을 다른 컴퓨터(한글이
설치된 Windows)로 옮기면 Python 설치 없이 그대로 실행할 수 있습니다.

1. PyInstaller 설치 (한 번만):

   ```
   pip install pyinstaller
   ```

2. 빌드:

   ```
   pyinstaller --onefile --name HwpZoteroInserter --hidden-import win32timezone 02_hotkey_listener.py
   ```

3. 빌드가 끝나면 `dist` 폴더 안에 `HwpZoteroInserter.exe`가 생성됩니다.

   ```
   cd dist
   dir
   ```

4. 그 `.exe`를 더블클릭(또는 터미널에서 `.\HwpZoteroInserter.exe`)으로 실행해서,
   Stage 2에서 한 것과 똑같이 한글 문서 + Zotero 인용 복사 + `Ctrl+Alt+Z` 테스트를
   다시 해봅니다.

**참고:** `pywin32`(한글 자동화에 쓰이는 패키지) 때문에 빌드 중이나 실행 중에
`win32timezone` 관련 에러가 날 수 있어서 미리 `--hidden-import`로 넣어뒀습니다.
그래도 에러가 나면 에러 메시지 전체를 그대로 알려주세요 — 흔한 문제라 대부분
`--hidden-import` 옵션을 하나 더 추가하는 것으로 해결됩니다.

`dist\HwpZoteroInserter.exe` 실행 결과(성공/실패, 에러 메시지)를 알려주시면
다음 단계(Zotero 실시간 연동)로 넘어가겠습니다.

Stage 3도 성공적으로 확인되었습니다 (.exe 단독 실행 성공).

## Stage 4a — Zotero 실시간 인용 삽입 (첫 시도)

여기서부터는 Zotero의 HTTP 통합 프로토콜을 직접 구현합니다. 공식 문서 페이지에
직접 접근하지 못하는 상태라 100% 정확한 사양대로 만들 수는 없어서, "일단 연결해서
Zotero가 실제로 뭘 요청하는지 로그로 확인하고, 그걸 보면서 하나씩 맞춰나가는" 방식으로
갑니다. 실패해도 정상입니다 — `zotero_debug.log` 내용이 다음 수정의 재료입니다.

**이번 버전이 하는 일:** 단축키로 Zotero 인용 검색창을 띄우고, 항목을 고르면 한글
커서 위치에 인용 텍스트가 삽입됨. 참고문헌(Bibliography)도 자동 생성되며, 각 항목이
줄바꿈되어 나오고, 스타일/언어 설정(`Ctrl+Alt+S`)에 따라 "et al."도 정상 출력됨.
(2026-09-20 기준 확인 완료: 인용 삽입, 참고문헌 생성/줄바꿈, 영어 로캘 적용 모두 정상.)

**이번 버전이 아직 못 하는 일:** 이미 삽입한 인용을 다시 수정하는 것(클릭해서 편집),
문서를 닫았다가 다시 열어도 인용 정보가 유지되는 것(스크립트를 껐다 켜면 그 전에
넣은 인용을 기억하지 못함), 참고문헌의 이탤릭체(저널명 등) 실제 서식 적용, 참고문헌
문단 서식(들여쓰기/줄간격) 적용.

1. 다시 설치:

   ```
   pip install -r requirements.txt
   ```

2. **Zotero를 실행해둡니다.** (Zotero 데스크톱 앱이 켜져 있어야 로컬 서버가 동작합니다.)
3. 한글에서 문서를 열고 인용을 넣을 위치에 커서를 둡니다.
4. 실행:

   ```
   python 03_zotero_bridge.py
   ```

5. **`Ctrl+Alt+C`**를 누릅니다.
6. Zotero 쪽에서 인용 검색 창이 뜨는지 확인합니다. (안 뜨면 6번은 건너뛰고 바로
   아래 로그를 확인해주세요.)
7. 뜬다면 스타일(예: APA)을 고르고, 문헌을 검색해서 선택한 뒤 확인을 눌러봅니다.
8. 한글 문서에 인용이 삽입되는지 확인합니다.

**`Ctrl+Alt+S`**: 인용 스타일/언어(로캘) 설정 창을 다시 엽니다. 예를 들어 인용
스타일을 바꾸고 싶거나, 참고문헌에 "et al." 대신 "외"/"기타"처럼 한국어로 나오는
것을 영어로 바꾸고 싶을 때 사용합니다. (Zotero 앱 자체가 한국어로 설정돼 있으면
스타일의 기본 언어도 한국어로 잡히는데, 이 창의 스타일 선택 옆 언어(Locale)
드롭다운에서 English(US) 등으로 바꾸면 됩니다. 이미 삽입된 인용/참고문헌은
스타일을 바꾼 뒤 `Ctrl+Alt+B`로 참고문헌을 다시 생성해야 새 설정이 반영됩니다.)

**어디까지 진행되든** `hwp_zotero` 폴더에 생긴 `zotero_debug.log` 파일 내용
전체를 복사해서 알려주세요. (터미널에도 같은 내용이 출력되니 터미널 내용을
복사해도 됩니다.) 이 로그가 있어야 정확히 어느 단계에서 막혔는지, 그리고
Zotero가 실제로 어떤 명령/인자를 보내는지 알 수 있어서 다음 수정을 할 수 있습니다.

## Stage 4b — 영속성 / 기존 인용 수정 / 참고문헌 서식

**새로 추가된 기능 3가지 (모두 처음 시도라 테스트가 필요합니다):**

1. **인용 정보가 문서 재오픈/스크립트 재시작 후에도 유지됨** — 단, **한글에서
   문서를 저장(Ctrl+S)해둔 상태**여야 합니다. 저장하면 문서와 같은 폴더에
   `<파일명>.hwp.zotero-fields.json` 파일이 생기는데, 이게 인용 정보 저장소입니다.
   (아직 저장 안 한 "제목없음" 문서는 재시작 후 "같은 문서"인지 구분할 방법이
   없어서 이 기능이 적용되지 않습니다 — 먼저 저장부터 해주세요.)

   **테스트 방법:**
   - 문서를 저장하고, 인용을 1~2개 넣습니다.
   - 스크립트를 Ctrl+C로 끄고 다시 `python 03_zotero_bridge.py`로 켭니다.
     (또는 한글 문서를 닫고 다시 엽니다.)
   - `Ctrl+Alt+B`로 참고문헌을 만들어봅니다. 재시작 전에 넣었던 인용까지
     전부 포함되어 나오는지 확인해주세요.

2. **기존 인용 클릭해서 수정** — 이미 삽입된 인용문의 **맨 왼쪽 글자 바로 앞**에
   커서를 두고 `Ctrl+Alt+C`를 누르면, 새로 추가하는 게 아니라 그 인용을 수정하는
   창이 뜹니다. (한글 API 특성상 커서가 인용의 정확히 왼쪽 끝에 붙어 있어야
   감지됩니다 — 인용 중간이나 바로 뒤에 있으면 새 인용 추가로 처리될 수 있습니다.)

   **테스트 방법:** 기존 인용 앞에 커서를 두고 `Ctrl+Alt+C` → 수정 창이 뜨는지,
   문헌을 하나 더 추가하거나 빼고 확인을 누르면 실제로 인용이 바뀌는지 확인.

3. **참고문헌 서식(이탤릭체/들여쓰기/줄간격)** — 저널명 등에 실제 이탤릭체가
   적용되고, Zotero 스타일이 지정한 들여쓰기(내어쓰기)/줄간격/항목간격이
   문단 서식으로 적용됩니다.

   **테스트 방법:** `Ctrl+Alt+B`로 참고문헌을 만든 뒤, 저널명 등이 기울임체로
   나오는지, 문단 모양(들여쓰기/줄간격)이 이상하지 않은지 확인.

**셋 다 이번이 첫 시도라서** 실제 한글에서 어떻게 동작할지 예측이 어려운
부분이 있습니다. 문제가 생기면 (특히 이탤릭체나 서식이 이상한 위치에 적용되는
경우) `zotero_debug.log` 내용과 함께 스크린샷을 보내주시면 로그의
"이탤릭 적용" / "참고문헌 문단 서식 적용" 관련 줄을 보고 원인을 찾을 수 있습니다.
