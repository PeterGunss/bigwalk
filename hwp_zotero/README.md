# 한글(HWP) ↔ Zotero 연동 프로젝트

## 목표

Zotero의 Microsoft Word 애드인과 비슷하게, 아래한글(한컴오피스 2024 이상, **Windows 전용**)에서
Zotero 인용을 삽입/관리할 수 있게 만드는 것이 최종 목표입니다.

이 문서는 실행 환경(Windows + 한컴오피스 한글)에서만 의미가 있습니다. 이 리포지토리 작업은
Linux 환경에서 이루어지므로, 아래 스크립트들은 **사용자가 직접 Windows PC에서 실행하고
결과를 알려주는 방식**으로 검증합니다.

## 왜 두 단계(Tier)로 나누는가

Zotero가 Word/LibreOffice에서 쓰는 실제 통합 방식(HTTP Integration Protocol)은
`Document.getFields`, `Field.setCode`, `Document.insertField` 등 15~20개의 명령을 문서
필드(누름틀) 모델에 정확히 매핑해서 구현해야 하는, 꽤 규모가 큰 프로젝트입니다.
처음부터 이걸 목표로 하면 검증에 오래 걸리고 실패했을 때 원인을 찾기도 어렵습니다.

그래서 다음과 같이 나눕니다.

- **Tier 1 (지금 진행 중) — "클립보드 삽입기"**
  Zotero에서 인용을 복사(Quick Copy)한 뒤, 한글 문서의 커서 위치에 서식과 함께
  바로 꽂아주는 도구. 완전한 실시간 연동은 아니지만 당장 실사용 가치가 있고,
  한글 자동화 자체가 이 컴퓨터에서 정상 동작하는지를 확인하는 발판이 됩니다.
- **Tier 2 (Tier 1 성공 후 검토) — "진짜 연동"**
  Zotero의 HTTP Integration Protocol을 구현해서 인용을 누름틀로 문서에 저장하고,
  스타일을 바꾸면 문서 전체가 갱신되는 수준까지 가는 것. Tier 1이 잘 동작하는 걸
  확인한 다음, 명령어 하나씩 나눠서 진행합니다.

## 사용 라이브러리

- [`pyhwpx`](https://pypi.org/project/pyhwpx/): 한글 오토메이션(COM) API를 파이썬에서 쉽게
  쓸 수 있게 감싼 오픈소스 패키지. 보안모듈 등록도 자동으로 처리해줍니다.

## 사전 준비 (Windows PC에서)

1. Windows에 한컴오피스 한글(2024 이상)이 정식 설치되어 있어야 합니다.
2. Python 3.9 이상 (이미 설치되어 있다고 하셨습니다).
3. VS Code 터미널에서 이 리포지토리를 클론(또는 내려받기)한 뒤, 아래 명령 실행:

   ```
   cd hwp_zotero
   pip install -r requirements.txt
   ```

## Stage 0 — 환경 점검

한글 자동화가 이 컴퓨터에서 정상적으로 동작하는지 확인하는 스크립트입니다.
**한글을 미리 켜두지 않아도 됩니다** — 스크립트가 자동으로 한글을 실행합니다.

```
python 00_check_env.py
```

- 한글 창이 뜨고, 새 문서에 테스트 문장이 자동으로 입력되면 성공입니다.
- 터미널에 `[성공]`으로 시작하는 메시지가 나오면 저에게 그 내용을 그대로 알려주세요.
- 에러가 나면 에러 메시지 전체를 그대로 복사해서 알려주세요. (개인정보가 포함된 경로 등은
  가려도 됩니다.)

Stage 0가 성공적으로 확인되었습니다 (한글 자동화 연결 정상 동작).

## Stage 1 — 클립보드 삽입기

Zotero에서 복사한 인용을, 지금 한글에서 커서가 있는 위치에 그대로 넣어주는 스크립트입니다.

1. requirements.txt가 바뀌었으니 다시 설치해주세요.

   ```
   pip install -r requirements.txt
   ```

2. 한글에서 원하는 문서를 열고, 인용을 넣을 위치에 커서를 둡니다. (이번에는 한글을
   미리 켜두셔야 합니다 — 이미 열려 있는 문서에 연결하는 방식입니다.)
3. Zotero에서 인용할 항목을 선택하고 "인용 복사"(예: `Ctrl+Shift+C`)를 실행합니다.
   - 어떤 서식(스타일)으로 복사될지는 Zotero 환경설정 > 내보내기(Export) 탭의
     "빠른 복사(Quick Copy)" 설정에서 미리 정할 수 있습니다.
4. 터미널에서 실행:

   ```
   python 01_insert_clipboard.py
   ```

5. 한글 문서의 커서 위치에 클립보드 내용이 그대로 삽입되면 성공입니다.

Stage 1도 성공적으로 확인되었습니다.

## 최종 목표 재정리 (Word 애드인 수준 + .exe 배포)

다음 목표는 "Word 애드인처럼 느껴지는 사용성"과 "Python 없이 실행되는 배포판" 두 가지입니다.
이를 위해 순서를 다음과 같이 잡았습니다.

- **Stage 2 (지금)** — 터미널에서 매번 스크립트를 실행하지 않고, 단축키 한 번으로 삽입.
- **Stage 3 (다음)** — PyInstaller로 `.exe` 파일로 패키징해서 Python 설치 없이 실행.
- **Stage 4+ (그다음, 가장 오래 걸림)** — Zotero의 HTTP 통합 프로토콜을 구현해서 인용을
  누름틀(필드)로 저장하고, 스타일 변경 시 문서 전체가 갱신되는 수준까지 (Tier 2).

## Stage 2 — 단축키 리스너

터미널을 열어둔 채로 실행해두면, 이후에는 단축키 한 번으로 클립보드 내용을 한글에 넣을 수 있습니다.

1. requirements.txt가 또 바뀌었으니 다시 설치해주세요.

   ```
   pip install -r requirements.txt
   ```

2. 실행:

   ```
   python 02_hotkey_listener.py
   ```

   "리스너를 시작합니다..." 메시지가 뜨면 이 창은 그대로 열어두세요 (최소화 가능).

3. 한글 문서에서 커서를 원하는 위치에 두고, Zotero에서 "인용 복사"를 실행합니다.
4. **`Ctrl+Alt+Z`**를 누르면 클립보드 내용이 한글에 삽입됩니다. 성공하면 짧은 "삐" 소리가
   나고, 실패하면 낮은 "부-" 소리가 납니다.
5. 리스너를 끝내려면 그 터미널 창에서 `Ctrl+C`.

만약 단축키를 눌러도 반응이 없다면, VS Code 터미널(또는 명령 프롬프트)을
**"관리자 권한으로 실행"** 한 뒤 다시 시도해주세요. (전역 단축키 후킹에 권한이
필요한 경우가 있습니다.)

`[성공]` 또는 `[실패]` 메시지와 함께 나오는 내용을 그대로 알려주시면 다음 단계로
넘어가겠습니다.
